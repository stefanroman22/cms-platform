# Reference Brands by Category

Naming 2–3 real-world reference brands is the single highest-leverage move in a design prompt. Anthropic's Cookbook page on frontend aesthetics confirms this: explicit reference brands "interpolate" the model toward a specific aesthetic attractor instead of the generic AI-slop default.

Use these in `<aesthetic_direction>` → `<reference_brands>`. Always pick brands that match the **chosen archetype**, not just the category.

## Rules for citing references

1. **Always pick 2–3, never 1.** Multiple brands let the model interpolate; one brand creates pure imitation.
2. **Match the archetype, not just the category.** "Aesop and Goop" is incoherent (different archetypes); "Aesop and Acne Studios" is coherent (both editorial-fashion).
3. **Prefer brands with strong, visit-able websites.** A reference brand that has shut down its site or relaunched into something bland is a wasted reference.
4. **Mix global and local where possible.** For a Dutch lead, citing "Aman and De Librije" beats "Aman alone" — the model picks up cultural cues.
5. **Avoid citing competitors.** If the lead is a restaurant in Amsterdam, don't cite another Amsterdam restaurant by name (the comparison hurts both).
6. **Update over time.** Brands age. If a reference brand here has visibly redesigned in a way that conflicts with the archetype, swap it.
